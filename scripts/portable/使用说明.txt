智能运维平台 便携版 {VERSION}（Windows x64）
==================================================

「解压即用」的多服务器滚动发布与智能运维平台。
内置 Python 运行时与全部依赖，无需安装 Python、pip 或任何开发环境。

【三步上手】
1. 把整个「智能运维平台-便携版」文件夹解压到任意目录
2. 双击「启动平台.bat」，等待浏览器自动打开
3. 首次登录：用户名 admin，密码 admin（首次登录会强制修改密码）

【入口一览】
- 启动平台.bat   Web 控制台（大屏/配置/发布/监控/告警/日志/AI 助手）→ http://127.0.0.1:5678
- 发布菜单.bat   命令行交互式发布（选环境 → 选服务/流水线 → 自动版本 → 确认执行）
- deploy.bat     命令行直发：deploy.bat --project <服务> --version <版本> [--env test]
- 关闭平台：关掉黑色命令行窗口即可（或在任务管理器结束 python.exe）

【数据与端口】
- 平台数据（配置库/日志/密钥）保存在包内 data\ 目录，首次启动自动创建
- 换电脑迁移：整个文件夹拷走即可，data\ 目录就是全部数据
- 默认端口 5678；被占用时自动顺延（以窗口显示地址为准）
- 仅监听本机 127.0.0.1；如需局域网访问，可编辑启动平台.bat 在 app.py 后加 --host 0.0.0.0

【能做什么】
- Web 大屏：服务状态卡片墙、发布/回滚、多服务流水线、金丝雀灰度
- 多运行时发布：Docker 容器、静态站点，以及 Java jar / Go / Rust 单二进制 + systemd（版本目录不可变、CURRENT 链接原子切换、回滚不重传产物）
- 实时监控 + 告警（企业微信/飞书/钉钉/邮件等六渠道）+ 日志中心
- AI 智能运维助手：自然语言生成发布计划 → 人工审批 → 执行闭环
- 全部 SSH 连接内置（paramiko 纯 Python），无需安装 ssh 客户端

【功能边界（请留意）】
- 平台本体（配置/监控/发布调度/审批/Agent 对话）零额外依赖，开箱即用
- 「在本机构建镜像」这一步需要本机装有 git / Maven / Docker（用于 git clone、mvn 打包、docker build）：
  · 没有工具链时：可用 --skip-build 复用已有镜像发布，或用 Web 界面做配置/监控/审批
  · 也可改在装有工具链的机器上执行构建
- 进程族发布（jar / Go / Rust）在平台机侧需要对应构建工具链：mvn、go 或 cargo（也可配置 build.go_home / build.cargo_home，或选 build_type=none 由外部投入产物并附同名 .sha256）；
  目标机侧只需要 Linux + systemd：jar 需已安装 JDK/JRE，Go 产物静态链接、Rust 产物按 target 依赖目标机 glibc，平台都不安装运行时
- 单实例进程发布在「停止 → 换版本 → 启动」期间有中断窗口，平台不承诺零停机；需要连续可用请用容器多实例
- AI 助手需要大模型 API（DeepSeek / OpenAI 兼容端点），在平台「智能助手」页配置；不配置不影响其他功能

【常见问题】
- 双击窗口一闪而过：右键「启动平台.bat」→「在终端中打开」运行，查看报错信息
- 浏览器没有自动打开：手动访问窗口中显示的地址
- 首次打开稍慢：正在自动建库并导入出厂配置，通常几秒内完成
